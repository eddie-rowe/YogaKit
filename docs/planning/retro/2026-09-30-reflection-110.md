# Reflection — #110 (test 007 T009: routine-log validator)

- The validator's logic was tangled with `fs` and `process.exit`. Injecting `exists`/`reflectionsFor` made every rule testable from a string, matching the `copy-lint.mjs` extraction pattern.
- Red proof used a stub module returning empty results, so tests failed on behaviour, not on a missing import.
- Test bug caught by the gate: a reflection path passed only to `reflectionsFor` also has to satisfy `exists`, as the real glob only returns files that exist.
- `validate:routine-log` output is byte-identical before and after the extraction.
