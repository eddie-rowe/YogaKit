   correction, not a contradiction.** `003`'s spec entity description and FR-023 both

   have invented a mechanism to satisfy requirement wording while violating Principle
   II.

   contract's own compliant copy says "not calculated" / "not derived" — a bare
   `.not.toContain()` would fail on correct copy. `#99`'s T055 check flags a word only
   when not immediately preceded by "not ", the same shape `VOICE-REST-LAPSE` already
   uses. Worth generalizing into the shared copy-lint matcher if a third case shows up.
5. **A CSS class doing double duty (colour + sizing) is a trap the moment one state
   needs to override only the colour half** — the FR-026 touch-target bug existed
   because `kk-chip`'s active branch swapped the whole class for a per-tone string
   instead of layering a colour on top. Splitting sizing into its own colour-free class
   made the fix additive instead of a specificity fight.
