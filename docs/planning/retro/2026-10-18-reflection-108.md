# Reflection — #108 composer inline depth escalation (2026-10-18)

- Pose detail has no per-item tap escalation; its "escalation" is the simple/advanced/expert chip ladder. The shared piece is therefore the ladder itself (`src/lib/pose-library/depth.ts`: steps, rank, `nextDepth`, reveal class) plus one `.kk-reveal` CSS rule, consumed by both `PoseDetailContent` and `ComposeFlowItem`.
- Composer keeps the composer-wide layer chips; a tap on the item name overrides that item's depth locally (null = follow the chips).
- The drag handle and reorder buttons are siblings of the toggle, so escalation cannot interfere with dragging (FR-057).
- #111 (`.claude/settings.json`) was blocked by the permission classifier as self-modification of hooks/permissions; held `auto/needs-human`. Future autodev runs should not queue issues that write agent hook/permission config as `auto-ok`.
