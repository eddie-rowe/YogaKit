## Pattern / anti-pattern

- `002-auth-tenancy-billing`'s schema doc (`docs/design/002-schema.md`) already
  forward-referenced most of `005`'s tables (`intentions`, `practice_checkins`,
  `practice_reflections`, `practice_ritual_state`, `practice_milestones`) and even named
  the RLS helper (`app_visible_student_ids()`) and the revoke RPC
  (`app_revoke_signal_sharing`) `005` needs — both already shipped in `002`'s migrations.
  §B of that doc explicitly says "CI assertion (stubbed now, filled in by 005)" for the
  RULE-V5 proof. This plan takes that seriously: T015 in `tasks.md` is framed as
  *filling* `002`'s stub, not creating a new obligation from scratch. Worth checking a
  prior feature's schema doc for "documented for context only, belongs to a later
  feature" sections before designing a new feature's schema — it can save real
  re-derivation and catches load-bearing helper functions that already exist.
- Decisions #3 and #6 needed different treatment even though the issue named them
  together: #3 (streak repair) is an engineering decision resolved by *not building
  something* — it gets a Constitution Check paragraph and a negative-assertion task
  (T034), not a copy contract. #6 (guidance tone) is genuinely a copy-style question and
  gets the `003`-style held contract (`contracts/guidance-tone.md`, `[OWNER SIGN-OFF]`)
  with schema/CI shipping now and prose withheld. Flagging both "for an owner nod" doesn't
  mean they take the same artifact shape — worth checking what kind of decision each one
  actually is before reaching for the copy-contract pattern reflexively.

## Codebase insight

`data/voice/voice-rules.json`'s copy-lint only scans `src/app` and `src/components`
(`scripts/lib/copy-lint.mjs`'s `SCAN_DIRS`) — `specs/` is out of scope by construction, so
planning prose in `plan.md`/`tasks.md` never needs to pass the banned-phrase check even
though it discusses streak/lapse copy at length. Confirmed this by reading the constant
directly rather than assuming from the issue's own "it likely won't, but check" hedge — a
one-line grep settled it in seconds and is worth doing before writing a paragraph
explaining why a docs PR was exempted from a gate that never would have applied.
